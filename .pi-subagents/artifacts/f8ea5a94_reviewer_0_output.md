## Review
- **High — `src/app/research.rs:1013-1019`:** When an escalation or embedding model’s backend is unavailable, the fallback sends the unresolved composite ID (for example, `openai:gpt-4.1`) to the research provider. Contradiction resolution can therefore fail after the expensive search pipeline completes. Use validated feature-model resolution and a provider-specific raw default instead.
- **Medium — `src/app/research.rs:650-676,710-757`:** Synthesizer, critic, second-round, and resolver calls propagate errors with `?` after publishing `working` but never publish `error`. Their lifecycle rows remain permanently active when the pipeline fails. Convert each call to emit a terminal error before returning.
- **Medium — `src/app/research.rs:412-421`:** A verifier error after any tokens emits `error` and immediately overwrites it with `done` because the buffer is nonempty. Conversely, a clean empty response leaves the verifier stuck on `working`. Track the stream outcome explicitly and emit exactly one terminal state.
- **Medium — `src/ui/popups/research_live.rs:20-24,44-57,74-75`:** Rows remain oldest-first, each lifecycle item now consumes two lines, and the stateless list has no scrolling. A normal six-searcher run fills the popup before later stages are appended, hiding the currently active synthesizer/verifier/writer; long details are also clipped rather than wrapped. Keep the viewport pinned to recent activity or add scroll state and wrapping.
- **Medium — `src/app/research.rs:317,619-644,685-704`:** Searcher identity includes only round/index/total, but steer batches reuse the same round. A steer batch with the same size overwrites every earlier searcher row, while the aggregate `search round N` row always collides. Include a distinct batch/steer identifier in lifecycle labels.
- **Low — `src/app/research.rs:459-467`:** A joined searcher panic is converted into a placeholder finding, but its per-searcher row remains `working`. Preserve the task’s label through the join result and terminalize it as an error.
